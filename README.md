This is the second submission for our Chess Project.
The team for this project is Team Jeeb, which only consists of Trey Pattillo.
All of the files from the first submission are still present in this repo, the ones that were edited or added for the second submission are Main.java, the gui package, and all the scripts inside said package, those being ChessBoardPanel, ChessGUI, GameState, and HistoryPanel.

This is a full implementation of the game Chess, where Players 1 & 2 take turns moving their pieces according to the rules of chess until one of the ending conditions is reached.
Contains implemented GUI Features 1-3, which are the Menu Bar with Game Controls, the Settings Window for Customization, and the Game History Panel with an Undo Button.
