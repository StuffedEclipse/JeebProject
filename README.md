This is the submission for the final phase of the Chess Project.
The team for this project is Team Jeeb, which only consists of Trey Pattillo.

All of the files from Phase 1 and 2 are in this repository, and work together to create a functioning Chess game with working UI and several added systems from Phase 2, such as move history and board customization.
The main file that was edited for the final submission was ChessGUI, which now connects backend functions from Board to use to make the game function correctly, and has gotten teh added feature of pawn promotion as well.
This is a full implementation of the game Chess, where Players 1 & 2 take turns moving their pieces according to the rules of chess until one of the ending conditions is reached.
